# Hádej číslo - Hra v Pythonu

## 📜 O hře

"Hádej číslo" je jednoduchá interaktivní hra, kde hráč musí uhádnout číslo, které je náhodně vybráno počítačem. Hráč má omezený počet pokusů, během kterých dostává nápovědu, zda je jeho tip vyšší nebo nižší než správné číslo.

## 🎮 Jak hrát

1. Spusť hru v Pythonu.
2. Počítač ti náhodně zvolí číslo mezi 1 a 20.
3. Zadej svůj tip a hra ti řekne, zda je tvé číslo menší, větší nebo správné.
4. Máš maximálně 5 pokusů, abys číslo uhodl!
